# Arjun Dhande - Portfolio

A modern, responsive portfolio website showcasing my skills, experience, and projects with smooth UI effects and a professional visual design.

## Live Demo
- Portfolio URL: [https://portfolio-pearl-two-92.vercel.app](https://portfolio-pearl-two-92.vercel.app)

## Features
- Responsive layout for desktop, tablet, and mobile
- Professional hero section with visual highlights
- Scroll reveal animations and polished hover interactions
- Expanded projects section with working external links
- Clean contact section with direct email and LinkedIn

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Run Locally
1. Clone the repository
2. Open the project folder
3. Launch `index.html` in your browser

## Deploy to Vercel
1. Install CLI (already done on this machine):
   - `npm install -g vercel`
2. Login to Vercel:
   - `vercel login`
3. Deploy production build from this folder:
   - `vercel --prod`
4. Copy the generated production URL and replace the `Portfolio URL` value in this README
